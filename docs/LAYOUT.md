# คู่มือไฟล์ออกแบบหน้าจอ SNP TPMS

หน้าจอของโปรแกรม SNP TPMS (บอร์ดจอเหลือง 320 x 240) วาดตามไฟล์ออกแบบ (JSON)
แก้ได้ในหน้าเว็บขั้นที่ 10 จอจริงเปลี่ยนทันทีโดยไม่ต้องลงโปรแกรมใหม่

## สั่งแก้เป็นภาษาไทย

พิมพ์บอก Claude ในแชทได้เลย เช่น
- "ทำตัวเลขล้อหน้าซ้ายสีฟ้า"
- "ย้ายชื่อล้อไปไว้ล่างตัวเลข"
- "เพิ่มข้อความ 'รถ 6 ล้อ ทะเบียน 70-1234' ตรงกลางจอ"

Claude จะเพิ่มหรือแก้แม่แบบใน `firmware/tpms/layouts/` แล้วนำขึ้นเว็บ จากนั้นเลือกแม่แบบใหม่จากรายการในขั้นที่ 10 จอจะเปลี่ยนตามทันที

## โครงไฟล์

```json
{
  "name": "ชื่อแม่แบบ",
  "bg": "#000000",
  "items": [
    {"type": "box", "x": 2, "y": 2, "w": 124, "h": 112, "r": 10, "bg": "{c.tile}", "border": "{fl.border}", "bw": 2, "pair": "fl"},
    {"type": "text", "x": 2, "y": 30, "w": 124, "align": "center", "font": 48, "color": "{fl.color}", "text": "{fl.p}"}
  ]
}
```

- จุด (0, 0) คือมุมซ้ายบน จอกว้าง 320 สูง 240 ชิ้นที่อยู่ท้ายรายการจะวาดทับชิ้นก่อนหน้า
- ใส่ได้สูงสุด 80 ชิ้น

### กล่อง (`"type": "box"`)

| ช่อง | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `x`, `y`, `w`, `h` | ตำแหน่งและขนาด | 0, 0, 20, 20 |
| `r` | ความมนของมุม | 0 |
| `bg` | สีพื้น | `{c.tile}` |
| `bw` | ความหนาขอบ (0 = ไม่มีขอบ) | 0 |
| `border` | สีขอบ | `{c.text}` |
| `pair` | กดค้างที่กล่องนี้เพื่อจับคู่เซนเซอร์กับล้อ: `fl` `fr` `rl` `rr` | ไม่มี |

### ข้อความ (`"type": "text"`)

| ช่อง | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `x`, `y` | มุมซ้ายบนของข้อความ | 0, 0 |
| `w` | ความกว้าง (ไม่ใส่ = กว้างตามข้อความ) | - |
| `align` | `left` `center` `right` (ใช้ได้เมื่อใส่ `w`) | `left` |
| `font` | ขนาดตัวอักษร `16` `24` หรือ `48` (48 มีแค่ตัวเลข จุด และขีด) | 16 |
| `color` | สีตัวอักษร | `{c.text}` |
| `text` | ข้อความ ใส่ตัวแปรได้ | ว่าง |
| `scroll` | ข้อความยาวเกิน `w` ให้เลื่อนวิ่ง (`false` = ขึ้นบรรทัดใหม่) | `false` |

สีเขียนแบบ `#RRGGBB` เช่น `#00AEEF` (ฟ้า) หรือใช้ตัวแปรสีด้านล่าง

## ตัวแปร (ใส่ใน `text` `color` `bg` `border` ได้)

ล้อ: `fl` = หน้าซ้าย, `fr` = หน้าขวา, `rl` = หลังซ้าย, `rr` = หลังขวา

| ตัวแปร | ค่า |
|---|---|
| `{fl.name}` | ชื่อล้อ (ตั้งในขั้นที่ 9) |
| `{fl.p}` | ลมยางในหน่วยที่ตั้งไว้ เช่น `34.2` |
| `{fl.psi}` `{fl.kpa}` `{fl.bar}` | ลมยางในหน่วยนั้นเสมอ |
| `{fl.temp}` | อุณหภูมิ (°C) |
| `{fl.batt}` | แบตเตอรี่ เช่น `91%` หรือ `2.8V` |
| `{fl.info}` | ข้อความสรุป เช่น `33°C \| 91%`, `กำลังจับคู่ 25s`, `ขาดการติดต่อ` |
| `{fl.status}` | `ปกติ` `ลมต่ำ` `ลมสูง/ร้อน` `ขาดการติดต่อ` `ยังไม่จับคู่` `รอสัญญาณ` `กำลังจับคู่` |
| `{fl.color}` | สีตามสถานะ (ปกติ / ลมต่ำ / ลมสูง / ขาดการติดต่อ) |
| `{fl.border}` | สีเตือนเมื่อลมผิดปกติ ไม่ผิดปกติเป็นสีช่องล้อ |
| `{unit}` | หน่วย `PSI` `kPa` `bar` |
| `{title}` | หัวข้อ (ตั้งในขั้นที่ 9) |
| `{status}` | ข้อความสถานะ เช่น `จับคู่ ล้อหน้าซ้าย แล้ว` |
| `{c.bg}` `{c.tile}` `{c.text}` `{c.ok}` `{c.low}` `{c.high}` `{c.stale}` | สีที่ตั้งในขั้นที่ 9 |

ตัวแปรที่พิมพ์ผิดจะแสดงเป็นข้อความ `{...}` ตามเดิมบนจอ ให้เห็นว่าต้องแก้

## เพิ่มแม่แบบ

1. สร้างไฟล์ใหม่ใน `firmware/tpms/layouts/` เช่น `my-truck.json`
2. เพิ่มชื่อใน `firmware/tpms/layouts/index.json`
3. รัน `node --test web/test/*.test.mjs` (ตรวจว่าทุกแม่แบบใช้ได้และไม่มีตัวแปรพิมพ์ผิด)

`default.json` คือหน้าจอเริ่มต้นที่ฝังมากับโปรแกรมบนบอร์ด
