# คู่มือไฟล์ออกแบบหน้าจอ SNP TPMS

หน้าจอของโปรแกรม SNP TPMS (บอร์ดจอเหลือง 320 x 240) วาดตามไฟล์ออกแบบ (JSON)
แก้ได้ในหน้าเว็บขั้นที่ 10 โดยไม่ต้องลงโปรแกรมใหม่

## ขั้นตอน: ดึงจากจอ → แก้ต่อ → ตรวจ → ทดลอง → บันทึก

1. **ดึงหน้าจอปัจจุบัน** พอเสียบจอแล้วเว็บพบโปรแกรม SNP TPMS หน้าจอที่จอใช้อยู่จะโหลดเข้าช่องแก้ไขให้เอง
   ถ้ากำลังแก้ค้างอยู่ เว็บจะไม่ทับงาน แต่ขึ้นข้อความให้กด "โหลดหน้าจอจากจอ" เอง (กด "เลิกทำ" ย้อนกลับได้)
2. **แก้ต่อ** ด้วยคำสั่งภาษาไทยหรือแก้ JSON ภาพตัวอย่างเปลี่ยนทันที จอจริงยังไม่เปลี่ยน
3. **ตรวจ** ทุกครั้งที่แก้ ผลอยู่ใต้ภาพตัวอย่าง ชิ้นที่มีปัญหามีกรอบแดงประในภาพ
   - ✗ ข้อผิดพลาด ส่งเข้าจอไม่ได้จนกว่าจะแก้: JSON ผิดรูปแบบ, ตัวแปรพิมพ์ผิด เช่น `{fl.pp}`, สีที่ไม่ใช่ `#RRGGBB`, ชิ้นอยู่นอกจอ, หน้าจอว่าง
   - ⚠ คำเตือน ส่งได้แต่ถามก่อนบันทึก: ล้นขอบจอ, ขนาด 48 ที่มีตัวอื่นนอกจากตัวเลข, ตัวอักษรที่ฟอนต์บนจอไม่มี (เช่น อีโมจิ), ข้อความยาวเกินช่อง, ตัวหนังสือสีกลืนกับพื้น
4. **ทดลองบนจอ (ยังไม่บันทึก)** จอแสดงแบบใหม่ให้ดูของจริง ดับไฟแล้วกลับเป็นแบบเดิม
   ไม่ชอบกด "ยกเลิกการทดลอง" จอกลับไปใช้แบบที่บันทึกไว้ งานในช่องแก้ไขยังอยู่
   (ติ๊ก "ทดลองบนจอทุกครั้งที่แก้" ถ้าอยากให้จอเปลี่ยนตามทุกครั้งที่แก้ ส่งเฉพาะแบบที่ไม่มี ✗)
5. **บันทึกลงจอ** เมื่อพอใจ ถ้าแบบนั้นยังไม่ได้ทดลองบนจอ หรือมีคำเตือน เว็บจะถามก่อน

## สั่งแก้เป็นภาษาไทยในหน้าเว็บ

ขั้นที่ 10 มีช่อง "สั่งด้วยภาษาไทย" พิมพ์แล้วกด Enter ภาพตัวอย่างเปลี่ยนทันที (ทดลองบนจอแล้วบันทึกตามขั้นตอนด้านบน) ไม่ใช้ AI ไม่มีค่าใช้จ่าย
(ตัวแปลคำสั่งอยู่ใน `web/thai_commands.js`) สั่งหลายข้อพร้อมกันได้ คั่นด้วย `,` หรือขึ้นบรรทัดใหม่

| อยากทำ | พิมพ์ว่า |
|---|---|
| เปลี่ยนสี | `เปลี่ยนสีตัวเลขล้อหน้าซ้ายเป็นฟ้า`, `ชื่อทุกล้อสีเหลือง`, `ขอบล้อหลังสีแดง`, `พื้นหลังสีน้ำเงิน`, `สีตัวเลข #FF00AA` |
| สีตามสถานะลมยาง | `ช่องทุกล้อสีตามสถานะ` (ตัวเลขในช่องจะเปลี่ยนเป็นสีดำให้เอง) |
| ขนาดตัวหนังสือ | `ขยายชื่อทุกล้อ`, `ย่อหัวข้อ` (มี 16, 24 และ 48 เฉพาะตัวเลข) |
| ย้าย | `ย้ายหัวข้อลง 10`, `เลื่อนข้อมูลล้อหน้าขวาซ้าย 5` (ไม่ใส่ตัวเลข = 10 จุด) |
| จัดแนว | `ชื่อทุกล้อชิดซ้าย`, `หัวข้อตรงกลาง` |
| เปลี่ยนข้อความ | `หัวข้อเป็น รถ 01` |
| เพิ่มข้อความ | `เพิ่มข้อความ 'ขับขี่ปลอดภัย' ด้านล่าง` (บอกได้ว่า ด้านบน / ตรงกลาง / ด้านล่าง / ตัวใหญ่ / สี...) |
| ซ่อน | `ซ่อนข้อมูลล้อหลังขวา` |
| ย้อนกลับ | กดปุ่ม "เลิกทำ" หรือพิมพ์ `เลิกทำ`, กลับหน้าจอเริ่มต้นพิมพ์ `เริ่มใหม่` |

ส่วนของจอที่รู้จัก: ตัวเลข, ชื่อ, ข้อมูล (อุณหภูมิ/แบต), ช่อง, ขอบ, หัวข้อ, สถานะ, พื้นหลัง
ล้อ: ล้อหน้าซ้าย, ล้อหน้าขวา, ล้อหลังซ้าย, ล้อหลังขวา, ล้อหน้า, ล้อหลัง, ทุกล้อ (ไม่บอกล้อ = ทุกล้อ)
สี: แดง เขียว น้ำเงิน ฟ้า เหลือง ส้ม ชมพู ม่วง ขาว ดำ เทา น้ำตาล ทอง หรือรหัส `#RRGGBB`

## ให้ Claude แก้ให้ (สำหรับแบบที่ช่องด้านบนทำไม่ได้)

พิมพ์บอก Claude ในแชทได้เลย เช่น
- "ทำตัวเลขล้อหน้าซ้ายสีฟ้า"
- "ย้ายชื่อล้อไปไว้ล่างตัวเลข"
- "เพิ่มข้อความ 'รถ 6 ล้อ ทะเบียน 70-1234' ตรงกลางจอ"

Claude จะเพิ่มหรือแก้แม่แบบใน `firmware/tpms/layouts/` แล้วนำขึ้นเว็บ จากนั้นเลือกแม่แบบใหม่จากรายการในขั้นที่ 10 จอจะเปลี่ยนตามทันที

## โครงไฟล์

```json
{
  "name": "ชื่อแม่แบบ",
  "bg": "#000000",
  "items": [
    {"type": "box", "x": 2, "y": 2, "w": 124, "h": 112, "r": 10, "bg": "{c.tile}", "border": "{fl.border}", "bw": 2, "pair": "fl"},
    {"type": "text", "x": 2, "y": 30, "w": 124, "align": "center", "font": 48, "color": "{fl.color}", "text": "{fl.p}"}
  ]
}
```

- จุด (0, 0) คือมุมซ้ายบน จอกว้าง 320 สูง 240 ชิ้นที่อยู่ท้ายรายการจะวาดทับชิ้นก่อนหน้า
- ใส่ได้สูงสุด 80 ชิ้น

### กล่อง (`"type": "box"`)

| ช่อง | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `x`, `y`, `w`, `h` | ตำแหน่งและขนาด | 0, 0, 20, 20 |
| `r` | ความมนของมุม | 0 |
| `bg` | สีพื้น | `{c.tile}` |
| `bw` | ความหนาขอบ (0 = ไม่มีขอบ) | 0 |
| `border` | สีขอบ | `{c.text}` |
| `pair` | กดค้างที่กล่องนี้เพื่อจับคู่เซนเซอร์กับล้อ: `fl` `fr` `rl` `rr` | ไม่มี |

### ข้อความ (`"type": "text"`)

| ช่อง | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `x`, `y` | มุมซ้ายบนของข้อความ | 0, 0 |
| `w` | ความกว้าง (ไม่ใส่ = กว้างตามข้อความ) | - |
| `align` | `left` `center` `right` (ใช้ได้เมื่อใส่ `w`) | `left` |
| `font` | ขนาดตัวอักษร `16` `24` หรือ `48` (48 มีแค่ตัวเลข จุด และขีด) | 16 |
| `color` | สีตัวอักษร | `{c.text}` |
| `text` | ข้อความ ใส่ตัวแปรได้ | ว่าง |
| `scroll` | ข้อความยาวเกิน `w` ให้เลื่อนวิ่ง (`false` = ขึ้นบรรทัดใหม่) | `false` |

สีเขียนแบบ `#RRGGBB` เช่น `#00AEEF` (ฟ้า) หรือใช้ตัวแปรสีด้านล่าง

## ตัวแปร (ใส่ใน `text` `color` `bg` `border` ได้)

ล้อ: `fl` = หน้าซ้าย, `fr` = หน้าขวา, `rl` = หลังซ้าย, `rr` = หลังขวา

| ตัวแปร | ค่า |
|---|---|
| `{fl.name}` | ชื่อล้อ (ตั้งในขั้นที่ 9) |
| `{fl.p}` | ลมยางในหน่วยที่ตั้งไว้ เช่น `34.2` |
| `{fl.psi}` `{fl.kpa}` `{fl.bar}` | ลมยางในหน่วยนั้นเสมอ |
| `{fl.temp}` | อุณหภูมิ (°C) |
| `{fl.batt}` | แบตเตอรี่ เช่น `91%` หรือ `2.8V` |
| `{fl.info}` | ข้อความสรุป เช่น `33°C \| 91%`, `กำลังจับคู่ 25s`, `ขาดการติดต่อ` |
| `{fl.status}` | `ปกติ` `ลมต่ำ` `ลมสูง/ร้อน` `ขาดการติดต่อ` `ยังไม่จับคู่` `รอสัญญาณ` `กำลังจับคู่` |
| `{fl.color}` | สีตามสถานะ (ปกติ / ลมต่ำ / ลมสูง / ขาดการติดต่อ) |
| `{fl.border}` | สีเตือนเมื่อลมผิดปกติ ไม่ผิดปกติเป็นสีช่องล้อ |
| `{unit}` | หน่วย `PSI` `kPa` `bar` |
| `{title}` | หัวข้อ (ตั้งในขั้นที่ 9) |
| `{status}` | ข้อความสถานะ เช่น `จับคู่ ล้อหน้าซ้าย แล้ว` |
| `{c.bg}` `{c.tile}` `{c.text}` `{c.ok}` `{c.low}` `{c.high}` `{c.stale}` | สีที่ตั้งในขั้นที่ 9 |

ตัวแปรที่พิมพ์ผิดจะแสดงเป็นข้อความ `{...}` ตามเดิมบนจอ ให้เห็นว่าต้องแก้

## เพิ่มแม่แบบ

1. สร้างไฟล์ใหม่ใน `firmware/tpms/layouts/` เช่น `my-truck.json`
2. เพิ่มชื่อใน `firmware/tpms/layouts/index.json`
3. รัน `node --test web/test/*.test.mjs` (ตรวจว่าทุกแม่แบบใช้ได้และไม่มีตัวแปรพิมพ์ผิด)

`default.json` คือหน้าจอเริ่มต้นที่ฝังมากับโปรแกรมบนบอร์ด
