# ฮาร์ดแวร์กล้องรุ่นแรก

ข้อมูลจากรูปถ่ายบอร์ด ยังไม่รู้ยี่ห้อและรุ่นของกล้อง

## บอร์ดหลัก (PCB สีดำ วันที่ 2022-10-12, 2238.06)

- โมดูล 4G: **Quectel EC200U-EU** (LTE Cat 1, ชิป Unisoc UIS8910) มีขั้วเสาอากาศ IPEX ข้างโมดูล
  - คลื่นที่รองรับ: B1/B3/B7/B8/B20/B28 ในไทยใช้ได้กับ B1, B3, B8, B28
  - ต่อ USB เข้าคอมแล้วจะเห็นหลายพอร์ต พอร์ต "AT Port" ใช้กับโปรแกรมนี้
  - ถ้าเห็นรหัส USB `1782:4D00` แสดงว่าโมดูลอยู่ในโหมดลงเฟิร์มแวร์
- กล้องมองหน้ารถ (เลนส์มุมกว้าง) อยู่บนบอร์ดนี้
- ช่อง microSD, พอร์ต mini-USB, ช่องซิม, ลำโพง/บัซเซอร์
- จุดบัดกรี `TX1/RX1`, `TX2/RX2`, `3V3`, `GND` = พอร์ตอนุกรม (UART) ใช้อ่าน log ตอนบูต
- ด้านหลังมีชิปประมวลผลหลักใต้ฝาครอบโลหะ (ยังไม่รู้รุ่น จะรู้จาก log ตอนบูต) และจุด `ETH_...` 4 ขา

## บอร์ดกล้องตัวที่สอง (PCB สีเขียว + บอร์ดดำรูปตัว U)

- กล้องมองคนขับ มีไฟอินฟราเรด 4 ดวง (D3–D6) ถ่ายกลางคืนได้ น่าจะใช้ตรวจจับคนขับง่วงหรือใช้โทรศัพท์
- ตัวเก็บไฟ (supercapacitor) 2.7V 5F 2 ตัว ไว้บันทึกไฟล์ต่อได้ตอนดับเครื่อง
- ถ่านกระดุมเลี้ยงนาฬิกา, ไมโครโฟน, ไฟ LED สถานะ 4 ดวง
- สายไฟหลายสีออกไปข้างนอก: ไฟเลี้ยง 12/24V, ACC, และอาจมีสายสัญญาณอื่น

## การต่อสาย USB-TTL เข้าจุด TX/RX

```
สาย USB-TTL (3.3V)      บอร์ดกล้อง
      GND  ----------  GND
      RX   ----------  TX1 (หรือ TX2)
      TX   ----------  RX1 (หรือ RX2)
      3V3  (ไม่ต่อ)
```

ลองทีละคู่ (TX1/RX1 แล้วค่อย TX2/RX2) ใช้ `python -m camtool console --port COMx --auto` แล้วเสียบไฟกล้องใหม่
คู่ที่มี log ตัวอักษรอ่านออก (เช่น `U-Boot`, `Linux version`) คือพอร์ตของชิปหลัก

# บอร์ด ESP32-2432S028 (จอเหลือง "Cheap Yellow Display")

- ชิป ESP32-WROOM-32, จอสัมผัส 2.8 นิ้ว (ILI9341), ช่อง microSD, ไฟ LED RGB, ช่องลำโพง
- USB ต่อผ่านชิป CH340 (`1A86:7523`) ต้องติดตั้งไดรเวอร์ CH340 บน Windows
- ไม่ใช่โมดูล 4G จึงไม่ตอบคำสั่ง AT ใช้ขั้นที่ 7 (ดู log) และขั้นที่ 8 (อ่าน/ลงโปรแกรม) บนหน้าเว็บ
- ถ้าเข้าโหมดลงโปรแกรมเองไม่ได้: กด BOOT ค้าง กด RST 1 ครั้ง แล้วปล่อย BOOT
