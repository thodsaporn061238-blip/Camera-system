# Camera-system

โปรแกรมสำรองข้อมูลเดิมและลงข้อมูลใหม่ให้กล้องติดรถแบบมี 4G และ GPS ในตัว
สำหรับกล้องที่ฮาร์ดแวร์ยังดี แต่ผู้ให้บริการเดิมเลิกให้บริการไปแล้ว เราจะเอากล้องกลับมาใช้กับระบบของเราเอง

รุ่นแรกที่รองรับ: กล้องที่ใช้โมดูล **Quectel EC200U-EU** (รายละเอียดบอร์ดอยู่ใน [docs/HARDWARE.md](docs/HARDWARE.md))
เพิ่มรุ่นอื่นได้ที่ `camtool/ports.py` (รหัส USB) และ `camtool/device.py` (คำสั่งอ่านข้อมูล)

## แผนงาน

| ขั้น | สิ่งที่ทำ | สถานะ |
|---|---|---|
| 1 | ต่อสาย หาพอร์ต อ่านข้อมูลเครื่อง (IMEI, รุ่น, เฟิร์มแวร์, ซิม, APN) | ✅ มีแล้ว |
| 2 | **สำรองข้อมูลเก่า** ไฟล์ทั้งหมดในโมดูล + log ตอนบูตของชิปหลัก | ✅ มีแล้ว |
| 3 | ทดสอบ GPS ในตัว | ✅ มีแล้ว |
| 4 | เขียนข้อมูลกลับลงกล้อง (restore / แก้ไฟล์ตั้งค่าแล้วเขียนกลับ) | ✅ มีแล้ว |
| 5 | อ่านข้อมูลที่สำรองไว้ หาว่ากล้องส่งข้อมูลไปเซิร์ฟเวอร์ไหน ด้วยโปรโตคอลอะไร (มักเป็น JT/T 808) | รอข้อมูลจากกล้องจริง |
| 6 | เปลี่ยนให้กล้องส่งข้อมูลมาเซิร์ฟเวอร์ของเรา + ทำเซิร์ฟเวอร์รับตำแหน่ง/วิดีโอ | รอขั้น 5 |
| 7 | ลงเฟิร์มแวร์ใหม่ทั้งชุด (ถ้าตั้งค่าอย่างเดียวไม่พอ) | รอไฟล์เฟิร์มแวร์ |

## เปิดโปรแกรมผ่านเว็บ (ง่ายที่สุด ไม่ต้องติดตั้งอะไร)

เปิดลิงก์ **https://thodsaporn061238-blip.github.io/Camera-system/** ด้วย Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์
แล้วกด "เชื่อมต่อ" เลือกพอร์ตของกล้อง ทำตามขั้นที่ 1–9 บนหน้าเว็บ

- เลือกพอร์ตครั้งแรกครั้งเดียว ครั้งต่อไปแค่เสียบสาย โปรแกรมเชื่อมต่อให้เองและเดาชนิดบอร์ด:
  ตอบคำสั่ง AT = โมดูล 4G (ใช้ขั้นที่ 2–6), ไม่ตอบ = บอร์ดอื่น เช่น ESP32 จะเปิดดูข้อความในขั้นที่ 7 และรีเซ็ตบอร์ดให้พิมพ์ log ตอนบูตออกมา
- รายชื่ออุปกรณ์ที่รู้จักอยู่ใน `web/devices.js`
- ขั้นที่ 8 สำหรับบอร์ด ESP32 (เช่น ESP32-2432S028 จอเหลือง): อ่านข้อมูลชิป, สำรองโปรแกรมเดิมทั้งหมดเป็นไฟล์ .bin, ลงโปรแกรมใหม่
  ใช้ไลบรารี [esptool-js](https://github.com/espressif/esptool-js) 0.7.0 ของ Espressif (สัญญาอนุญาต Apache-2.0) เก็บสำเนาไว้ที่ `web/vendor/`
- ขั้นที่ 9 ติดตั้งและตั้งค่าจอลมยาง SNP TPMS (ดูหัวข้อถัดไป)
- ขั้นที่ 6 มีปุ่มคำสั่ง AT สำเร็จรูป (ซิม สัญญาณ GPS ไฟล์) ขั้นที่ 7 พิมพ์คำสั่งเข้าชิปหลักได้ (U-Boot / Linux) พร้อมปุ่มสำเร็จรูป
  ปุ่มสีส้มเปลี่ยนค่าในเครื่อง กดแล้วจะแค่ใส่คำสั่งในช่องให้ตรวจก่อน ไม่ส่งทันที แก้รายการปุ่มได้ที่ `web/commands.js`
- หน้าเว็บคุยกับกล้องผ่าน USB บนเครื่องคุณโดยตรง ข้อมูลกล้องไม่ถูกส่งขึ้นอินเทอร์เน็ต
- ไฟล์สำรองจากหน้าเว็บ (.zip) แตกไฟล์แล้วใช้กับคำสั่ง `restore` ของโปรแกรม Python ได้
- โค้ดหน้าเว็บอยู่ในโฟลเดอร์ `web/` GitHub นำขึ้นออนไลน์ให้เองทุกครั้งที่โค้ดเข้า `main` (`.github/workflows/pages.yml`)
- ลองบนเครื่องตัวเอง: `cd web` แล้ว `python -m http.server 8000` จากนั้นเปิด http://localhost:8000

## โปรแกรมจอลมยาง SNP TPMS (`firmware/tpms`)

โปรแกรมสำหรับบอร์ด ESP32-2432S028 (จอเหลือง) แสดงลมยาง อุณหภูมิ แบตเตอรี่ของเซนเซอร์ 4 ล้อ ที่ส่งค่าผ่าน Bluetooth

- ติดตั้ง: หน้าเว็บขั้นที่ 9 กด "ติดตั้ง / อัปเดตโปรแกรม SNP TPMS" (ไฟล์ `firmware/snp-tpms.bin` GitHub สร้างให้ทุกครั้งที่โค้ดเข้า `main`)
- ตั้งค่าจากหน้าเว็บขั้นที่ 9 ได้โดยไม่ต้องลงโปรแกรมใหม่: หัวข้อ ชื่อล้อ หน่วย (PSI/kPa/bar) เกณฑ์เตือน สีทุกส่วน ความสว่าง เสียงเตือน ทิศจอ
- จับคู่เซนเซอร์: เลือกจากรายการเซนเซอร์บนหน้าเว็บ หรือกดค้างที่ช่องล้อบนจอแล้วถือเซนเซอร์ไว้ใกล้จอ
- รองรับเซนเซอร์แบบ `TPMS1_xxxxxx` (manufacturer data 18 ไบต์) รุ่นอื่นจะเห็นเป็นข้อมูลดิบบนหน้าเว็บ กด "บันทึกข้อมูลเซนเซอร์เป็นไฟล์" แล้วส่งให้ผู้พัฒนาเพิ่มตัวแปลงใน `firmware/tpms/src/tpms_decode.cpp`
- คำสั่งผ่านสาย USB (115200, JSON ทีละบรรทัด): `{"get":"cfg"}`, `{"set":{...}}`, `{"pair":0}`, `{"unpair":0}`, `{"raw":true}`, `{"reset":"cfg"}`, `{"beep":true}`
- สร้างเอง: `bash tools/gen_fonts.sh && pio run -d firmware/tpms && bash tools/merge_firmware.sh`
- ฟอนต์ภาษาไทย Sarabun (SIL Open Font License) สร้างเป็นฟอนต์ของจอด้วย lv_font_conv ตอน build

## ติดตั้งโปรแกรม Python (สำหรับใช้แบบพิมพ์คำสั่ง)

1. ติดตั้ง [Python 3.10 ขึ้นไป](https://www.python.org/downloads/) ตอนติดตั้งติ๊ก **Add python.exe to PATH**
2. ติดตั้งไดรเวอร์ USB ของ Quectel (ค้นคำว่า "Quectel USB Driver Windows") ถ้าใช้สาย USB-TTL ให้ติดตั้งไดรเวอร์ของชิปในสายด้วย (CH340 / CP210x)
3. ดาวน์โหลดโค้ดนี้ แล้วเปิด Command Prompt ในโฟลเดอร์นี้:

```
pip install -r requirements.txt
```

## วิธีใช้

**ก่อนลงข้อมูลใดๆ ต้องสำรองข้อมูลเดิมก่อนทุกครั้ง**

```
python -m camtool scan                          :: หาพอร์ต (โมดูล 4G จะมีหลายพอร์ต ใช้ตัวที่ชื่อ "AT Port")
python -m camtool info   --port COM5            :: อ่านข้อมูลเครื่อง
python -m camtool backup --port COM5            :: สำรองทุกอย่างลงโฟลเดอร์ backups\<IMEI>_<วันเวลา>
python -m camtool gps    --port COM5            :: ทดสอบ GPS (วางกล้องให้เห็นท้องฟ้า)
python -m camtool at     --port COM5 "AT+QGMR"  :: ส่งคำสั่ง AT เอง
python -m camtool restore --port COM5 backups\866..._20261025-101500   :: เขียนไฟล์กลับลงกล้อง
```

อ่าน log ตอนบูตของชิปหลักผ่านจุด TX/RX บนบอร์ด (ใช้สาย USB-TTL แบบ **3.3V**):

```
python -m camtool console --port COM7 --auto    :: เดาความเร็วอัตโนมัติ แล้วบันทึกลงไฟล์ console_*.log
```

ส่งโฟลเดอร์ `backups\...` และไฟล์ `console_*.log` ให้ผู้พัฒนา เพื่อทำขั้นที่ 5 ต่อ

## ข้อควรระวัง

- ห้ามถอดสายหรือดับไฟระหว่าง `restore`
- สาย USB-TTL ต้องเป็น 3.3V ถ้าใช้ 5V อาจทำให้บอร์ดเสีย และไม่ต้องต่อขาไฟ 3V3 ของสายเข้าบอร์ด ต่อแค่ TX, RX, GND
- ไฟล์สำรองมี IMEI และค่าตั้งของเครื่อง ไม่ต้อง commit ขึ้น GitHub (`.gitignore` กันโฟลเดอร์ `backups/` และไฟล์ `.bin` ไว้แล้ว)
