Camera System

สำรองข้อมูลเดิมและลงข้อมูลใหม่ให้กล้องติดรถ 4G + GPS (ทดสอบกับโมดูล Quectel EC200U)

เบราว์เซอร์นี้ต่อกล้องไม่ได้

ต้องเปิดหน้านี้ด้วย Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ (มือถือและ Safari/Firefox ใช้ไม่ได้)

1. เชื่อมต่อกล้อง

  1. เสียบสาย USB จากกล้องเข้าคอม (ติดตั้งไดรเวอร์ Quectel USB ก่อนถ้ายังไม่เคย)
  2. ครั้งแรก: กด "เชื่อมต่อ" แล้วเลือกพอร์ต (โมดูล 4G เลือกพอร์ตที่ชื่อ AT Port, บอร์ด ESP32 เลือก USB-SERIAL CH340)
  3. ครั้งต่อไป: แค่เสียบสาย โปรแกรมเชื่อมต่อและเดาชนิดบอร์ดให้เอง ไม่ต้องกดอะไร
ยังไม่ได้เชื่อมต่อ

2. ข้อมูลเครื่อง

IMEI รุ่น เวอร์ชันเฟิร์มแวร์ ซิม และ APN

3. สำรองข้อมูลเดิม

อ่านข้อมูลเครื่องและไฟล์ทั้งหมดในโมดูล บันทึกเป็นไฟล์ .zip ลงเครื่อง ทำขั้นนี้ก่อนเขียนอะไรลงกล้องทุกครั้ง


    


    

      
4. เขียนข้อมูลลงกล้อง

      
เลือกไฟล์ .zip จากขั้นที่ 3 ระบบจะตรวจไฟล์ก่อน แล้วเขียนทับของเดิมในกล้อง ห้ามถอดสายระหว่างเขียน

      

        
        
      

      

    


    

      
5. ทดสอบ GPS

      
วางกล้องให้เห็นท้องฟ้า ครั้งแรกอาจใช้เวลา 1–3 นาที

      

        
        
      

      

    


    

      
6. ส่งคำสั่ง AT (โมดูล 4G)

      
กดปุ่มสำเร็จรูป หรือพิมพ์คำสั่งเองแล้วกด Enter ปุ่มสีส้มจะเปลี่ยนค่าในกล้อง ต้องสำรองข้อมูลก่อน

      

      

        
        
      

      

    


    

      
7. log ตอนบูต และสั่งงานชิปหลัก (จุด TX/RX บนบอร์ด)

      
ใช้สาย USB-TTL แบบ 3.3V ต่อ GND, TX กล้อง → RX สาย, RX กล้อง → TX สาย เชื่อมต่อที่ความเร็ว 115200 แล้วกดเริ่ม จากนั้นเสียบไฟกล้องใหม่
        ถ้าตัวอักษรอ่านไม่ออก ให้ตัดการเชื่อมต่อแล้วลองความเร็วอื่น

      

        
        
        
        
      

      

      
พิมพ์คำสั่งเข้าชิปหลัก

      
ใช้ได้เมื่อบอร์ดเปิดช่องรับคำสั่งไว้ (log จะขึ้น => หรือ # หรือ login:)
        ถ้าอยากเข้า U-Boot ให้กด "กด Enter รัว 10 วินาที" แล้วเสียบไฟกล้องใหม่ทันที

      

      

        
        
        
      

    


    

      
8. บอร์ด ESP32: อ่านและลงโปรแกรม

      
สำหรับบอร์ด ESP32 เช่น ESP32-2432S028 (จอเหลือง) ถ้าต่อไม่ติด ให้กดปุ่ม BOOT บนบอร์ดค้างไว้ กด RST 1 ครั้ง แล้วปล่อย BOOT จากนั้นลองใหม่
        สำรองโปรแกรมเดิมก่อนลงโปรแกรมใหม่ทุกครั้ง

      

        
        
        
        
      

      

      
ลงโปรแกรมใหม่

      

        
        
        
        
      

      
      

    


    

      
9. จอลมยาง SNP TPMS (จอเหลือง)

      
โปรแกรมจอแสดงลมยาง 4 ล้อที่เราเขียนเอง ลงครั้งเดียวแล้วเปลี่ยนชื่อ สี หน่วย และจับคู่เซนเซอร์จากหน้านี้ได้เลย ไม่ต้องลงโปรแกรมใหม่
        ก่อนลงครั้งแรก สำรองโปรแกรมเดิมในขั้นที่ 8 ก่อน

10. ออกแบบหน้าจอ (เห็นผลบนจอทันที)

      
แก้ไฟล์ออกแบบด้านล่าง ภาพตัวอย่างและจอจริงจะเปลี่ยนตามทันที (ออกแบบได้แม้ยังไม่ต่อจอ) พอใจแล้วกด "บันทึกลงจอ" ใช้ได้กับโปรแกรม SNP TPMS (ขั้นที่ 9)
        อยากแก้เป็นภาษาไทย ให้พิมพ์บอก Claude ในแชท เช่น "ทำตัวเลขล้อหน้าซ้ายสีฟ้า" แล้วเลือกแม่แบบที่ Claude เพิ่มให้จากรายการ
        ตัวแปรที่ใช้ได้ดูใน คู่มือไฟล์ออกแบบ

11. ไฟล์ในบอร์ด

      
ดูไฟล์ทั้งหมดที่เก็บในบอร์ด (โปรแกรม SNP TPMS) ดาวน์โหลด คัดลอก ลบ หรือเอาไฟล์จากคอมพิวเตอร์เขียนลงบอร์ด
        หน้าจอที่บันทึกไว้อยู่ในไฟล์ /layout.json
